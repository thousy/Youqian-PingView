# Youqian-PingView - 统信 UOS Desktop V25 批量网络监控工具

> 原版 Windows 工具 **PingInfoView** 的原生 Linux / 统信 UOS 重构与升级版本。  
> 专为 **统信 UOS Desktop V25** 桌面环境量身定制，免 root 权限运行，开箱即用。

---

## 🌟 核心特性

1. **经典双窗格总览与明细设计**：
   - **上窗格（大盘列表）**：多主机实时存活状态、成功/失败次数、丢包率(%)、最后延迟、平均/极值延迟、TTL、连续失败次数。
   - **下窗格（流水明细）**：选中某台主机后，下窗格自动同步滚动显示该主机每次探测的明细日志（时间、延迟、状态、响应IP）。
2. **高并发与免 Root 权限**：
   - 核心探测采用 Linux 原生异步子进程池与多线程调度，**完全无需 root 权限**，普通用户即可顺畅运行。
3. **强大的地址录入格式（完全兼容原版）**：
   - **单个 IP / 域名**：`192.168.1.1`、`www.baidu.com`
   - **IP + 描述**：`192.168.1.1 核心主路由器`、`192.168.1.2 OA办公服务器`
   - **CIDR 子网段（自动批量展开）**：`192.168.1.0/24 财务部`、`10.0.0.0/29`
   - **连续 IP 范围**：`192.168.1.1-192.168.1.50 生产车间终端`
   - **TCP 端口连通性探测**：`192.168.1.100:80 Web服务器`、`10.10.1.5:443`
4. **可视化与交互**：
   - 状态圆点指示灯（绿色正常、红色超时/宕机、黄色/灰色待命）；
   - 异常/超时主机浅红底色高亮醒目提醒；
   - 实时搜索过滤（支持根据 IP、域名、备注关键词即输即搜）；
   - 筛选视图（显示全部 / 仅显示存活 / 仅显示异常）；
   - 支持 HTML / CSV 统计报表导出。
5. **异常告警**：
   - 连续失败次数达到阈值自动发出系统提示蜂鸣音，有效提醒网络运维故障。

## 🚀 统信 UOS Desktop V25 运行方法

### 方式一：免安装直接启动（推荐）

在 UOS 终端中进入项目目录，执行一键启动脚本即可：

```bash
chmod +x run_uos.sh
./run_uos.sh
```

> 💡 脚本会自动检测并提示安装 `python3-pyqt5` 依赖（如系统未安装，脚本会自动调用 `sudo apt install -y python3-pyqt5`）。

### 方式二：一键安装到系统应用启动器与桌面

若希望像普通桌面软件一样在 UOS 的**启动器菜单**或**桌面快捷方式**中直接点击打开：

```bash
chmod +x install_uos.sh
sudo ./install_uos.sh
```

安装完成后：
- 可以在 UOS 桌面找到 **批量网络监控工具 (PingInfoView)** 快捷方式；
- 可以在系统的应用启动器（所有程序 -> 网络工具）中直接搜索打开。

## ⌨️ 常用快捷键

| 快捷键 | 功能说明 |
| :--- | :--- |
| **F5** | 开始 / 恢复监控探测 |
| **F6** | 停止 / 暂停监控探测 |
| **F8** | 打开目标地址编辑录入对话框 |
| **F9** | 打开探测参数与告警设置对话框 |
| **鼠标右键** | 复制单元格、复制整行、禁用/启用当前主机、立即单独探测 |
