# Youqian PingView

> 专为 **Linux / 统信 UOS Desktop (V25/V20)** 打造的原生图形化多目标批量网络探测与监控工具。  
> 深度对标 Windows 经典网络工具 **PingInfoView** 的架构与功能，具备双引擎保障、免 root 运行、开箱即用。

---

## 🌟 核心特性 (Features)

1. **经典双窗格（上下分栏）联动视图**：
   - **上窗格（监控大盘）**：实时展示所有主机的存活状态、红/绿指示灯、响应 IP、丢包率(%)、最后延迟、平均延迟、极值延迟、TTL/HLIM 跳数、连续失败次数与备注信息；异常主机浅红底色高亮。
   - **下窗格（历史明细流水）**：选中某台主机后，自动联动同步呈现该主机的每次探测时间、延迟与状态流水，支持列宽自由拖拽调整。
2. **多目标批量录入与智能语法解析**：
   - 支持单个 IP 与域名（如 `192.168.1.1`、`www.baidu.com`）；
   - 支持 IP 与描述混排（如 `192.168.1.1 核心交换机`）；
   - 支持 **CIDR 子网段批量展开**（如 `192.168.1.0/24 办公网` 会自动展开为网段内所有可用主机）；
   - 支持 **连续 IP 范围批量展开**（如 `192.168.1.1-192.168.1.50`）；
   - 支持 **TCP 端口连通性探测**（如 `192.168.1.100:80 Web服务器`）。
3. **原生 100% IPv6 深度支持**：
   - 支持标准 IPv6 地址（如 `2400:3200::1`、`::1`）及域名解析；
   - 自动适配 Linux `ping -6` 与 `ping6` 底层命令，免 root 权限并发探测；
   - 自动抓取 IPv6 专属的 **HLIM**（Hop Limit 跳数限制）与高精度毫秒延迟；
   - 支持 IPv6 带端口 TCP 探测（如 `[2400:3200::1]:443`）。
4. **灵活多选与规范复制**：
   - 支持按住键盘 `Ctrl` 键跳选任意行（如 1、3、5 行）；
   - 支持按住键盘 `Shift` 键连续范围多选（如选中 2-5 行）；
   - 快捷键 `Ctrl+C` 复制整行：第 1 行自动输出规范的 Tab 制表符表头，后续行依次输出选中的数据行，粘贴至 Excel 或记事本均完美对齐。
5. **经典属性查看窗口**：
   - 鼠标双击或右键「属性 (Alt+Enter)」弹出独立属性面板，清晰汇总 20+ 项参数指标。
6. **活动故障实时监控与自愈移出**：
   - 在「仅显示失败/异常」模式下，后台一旦探测到新的断网/故障主机，**毫秒级即时弹现在大盘页面上**；故障恢复后自动从列表中移出；
   - 支持右键「禁用此项探测」，禁用后立即从失败列表中隐藏。
7. **双引擎零依赖保障**：
   - **首选引擎**：PyQt5 高清现代桌面界面；
   - **回退引擎**：内置 Python 标准库原生轻量图形引擎（完全无需安装任何第三方库，在统信未激活或内网环境下 100% 确保开箱即用）。

## 🚀 安装与运行 (Installation & Usage)

### 方式一：免安装绿色运行（最快捷）

在终端中进入项目目录，执行：

```bash
chmod +x run_uos.sh
./run_uos.sh
```

### 方式二：双击 DEB 包安装（推荐）

通过项目构建脚本一键生成 `.deb` 安装包：
```bash
python3 build_deb.py
```
在统信 UOS 文件管理器中**双击 `uospingview_1.0.2_all.deb`**，点击「安装」即可安装至系统启动器与桌面。

### 方式三：脚本一键系统级部署

```bash
chmod +x install_uos.sh
sudo ./install_uos.sh
```

## ⌨️ 常用快捷键 (Shortcuts)

| 快捷键 | 功能说明 |
| :--- | :--- |
| **F5 / Ctrl + R** | 立即发起新一轮并发探测并刷新大盘 |
| **F6** | 停止 / 暂停探测循环 |
| **F8** | 打开目标地址编辑与批量录入窗口 |
| **F9** | 打开探测频率、超时、并发数与告警设置窗口 |
| **Ctrl + C** | 复制选中行（第一行为表头，第二行起为数据行） |
| **Alt + Enter** | 打开选中主机的详细属性查看窗口（或直接双击该行） |
